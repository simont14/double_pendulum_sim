## Project

Numerical simulation and chaotic dynamics analysis of a double pendulum, implemented in Python using NumPy and Matplotlib.

## Commands

```bash
# Run all tests
pytest tests/

# Run a single test file
pytest tests/test_smoke.py

# Run a specific test by name
pytest tests/ -k "test_name"
```

No build step is required — this is a pure Python project. Activate the virtual environment (`.venv/`) before running commands.

## Architecture

The project is in early development. The intended structure:

- `src/` — simulation and analysis modules (currently empty)
- `tests/` — pytest test suite
- `notebooks/` — Jupyter notebooks for exploratory analysis and visualization
- `figures/` — output plots and figures generated by the simulation

The stack is NumPy (numerical integration, array operations) and Matplotlib (visualization). Simulation code will live in `src/`; notebooks in `notebooks/` import from `src/` and produce figures saved to `figures/`.

## Dependencies

Managed via `requirements.txt`. Key packages: `numpy`, `matplotlib`, `pytest`.
